# Shoe Store Shopping Cart 👟

## 📌 About the Project

The Shoe Store Shopping Cart is a simple and interactive shopping cart application developed using React.js. It allows users to browse shoes, add products to the cart, update quantities, remove products, and calculate the total price.

This project demonstrates the use of React Hooks, especially the `useState` Hook, for managing component state.

## ✨ Features

- Display shoe products with images and prices.
- Add products to the shopping cart.
- Increase or decrease product quantities.
- Remove products from the cart.
- Calculate the total price dynamically.
- Interactive and user-friendly interface.
- Responsive layout using Tailwind CSS.

## 🛠️ Technologies Used

- HTML5
- React.js
- JavaScript
- Tailwind CSS
- Vite

## 🚀 How to Run the Project

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Open the Project Folder

```bash
cd ankita-task-25
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Start the Development Server

```bash
npm run dev
```

### Step 5: Open in Browser

Open the local URL displayed in the terminal, usually:

```text
http://localhost:5173/
```

## ⚛️ React Hook Used

### useState()

The `useState()` Hook is used to manage the shopping cart state, product quantities, and other interactive changes in the application.
